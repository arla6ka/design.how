# Review

1. Fix the scope: the named screen or flow, else the branch's changed screens, else the five top routes.
2. Run `ui-review` on it with the installed system's rules first, then the default criteria.
3. Check the return on its captures and commands. Rerun one probe it reports.
4. Report the answer line, the ship line and the ranked findings.
5. Offer the fix as one prompt per `blocking` finding, each a check that fails on the current build.

Done when every finding has a capture and a criterion.
