# Vault

Visuals an agent can build into a page: moving type, shader fields and small interface pieces. Each one is its own skill, with a brief of what makes the effect, the FIXED steps, the VARIABLE values and a React and TypeScript template. Install one by name:

```bash
npx skills add https://design.how/vault/warp-type
```

Every visual pauses off screen and on a hidden tab, draws one still frame under reduced motion, caps the pixel ratio at 2 and cleans up when it unmounts. Each skill's `scripts/check.mjs` checks that your copy still does. Type falls back to system faces, and a visual built on photos or clips ships placeholders at the paths it reads, for you to replace with your own.

Watch them all at [design.how/vault](https://design.how/vault).
