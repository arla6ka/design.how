# Placeholder media for Hover video button

Every file here is a placeholder: a neutral gradient image or a short abstract clip, at the path the code asks for. The live
visual at https://design.how/vault/hover-video uses real pictures, which the skill does not ship. Put your own image or video at
each path below, keeping the file name, or change the paths in the template's params.

Copy this folder to the app's static folder as `public/hover-video/`, so `/hover-video/buttons/boop.alpha.webm` serves.
`runtime/media.ts` reads from `MEDIA_BASE`, which is `/hover-video`.
